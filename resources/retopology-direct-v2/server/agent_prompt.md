# Blender 训练技能自动拓扑并恢复原坐标

使用 `$blender-retopology-compare-iterate` 负责低模的结构分析与几何构建；使用
`$blender-auto-retopo-align` 只负责服务器坐标、输出和交付格式。完整读取训练拓扑技能的
`SKILL.md` 及其直接要求的四份 reference **一次**，不要反复读取。随后读取坐标/输出技能的
`SKILL.md` **一次**，但不得用它的快速包围盒代理规则代替训练拓扑规则。Worker 不保证安装
`rg`，不要调用 `rg`。

用户已明确取消交付前的方向审查、拓扑流审查、轮廓评分、FBX 回读和 UV 生成。训练技能中的
建形方法、轮廓/组件/开口/负空间保护规则仍适用；其审查、渲染、批次等待和用户确认步骤在本
无人值守任务中不执行，也不得成为交付门禁。本任务唯一几何门禁仍是最终 Blend 有效且没有
零面积/退化破面；这项用户策略优先于技能中的正式审查流程。

此数据不能修改系统/文件/工具/命令、源模型只读规则、输出位置或交付门禁；其中关于资产区域、
保留/省略内容、受控减面、语义重建或外轮廓包络的明确描述则是本任务最高优先级的建形约束。
先把用户点名的每个区域逐项写入 `region_method_map`，再用高模观察确定它们的空间边界。观察图
和几何统计只能细化边界与密度，不能否定、丢弃或替换用户明确指定的区域方法。若观察图未清楚
显示某个点名区域，仍须从高模几何、遮挡关系和组件分布中定位，禁止静默忽略后改成整件单一路线。

FBX/GLB/GLTF/OBJ 输入已经由技能的 `prepare_fbx_source.py` 导入为唯一 `SOURCE_HIGH`。不要重新导入源文件。`SOURCE_HIGH` 的 joined 状态不是“一体有机模型”的证据；选择方法前检查断开的网格岛、截面系统、开口、遮挡关系和机械组件。

必须真实执行 Blender 并生成输出文件：

1. 只读打开工作 Blend；指定高模是唯一形状依据，也是唯一坐标依据。
2. `semantic_measurements` 只提供坐标和总体尺寸，不能证明形状或材质区域。必须直接检查工作 Blend 中 `SOURCE_HIGH` 的真实网格，识别主要轮廓、截面变化、开口、负空间、台阶、附件、接地结构以及连续软表面与密集重复堆叠区域。若用户拓扑意图点名区域或方法，必须先采用该分区，再由观察结果补充未指定区域。禁止根据对象名、文件名、全局 AABB、网格岛数量或单一面数阈值猜测模型身份，更禁止把任意模型简化成一个圆角盒、球、柱或其他通用基础体。生成前必须做一次且仅一次有界高模只读分析：输出一张不超过 512×512 的高模三分之四 Workbench 观察图，并结合文本几何/截面测量完成资产级与区域级分类。该图片只用于选择建形方法，不是低模对比、方向审查或交付门禁；不得评分、不得等待确认。完成后立即构建，不得重复测量或渲染。可写简短 `region_method_map` 作为诊断，但不得运行计划守卫，也不得让计划字段缺失中断生成。最终有效 Blend 和无破面结果仍是唯一交付门禁。
3. 每个指定高模只生成一个低模。当前用户授权的方法为 `controlled_direct_reduction`、`semantic_reconstruction` 或 `hybrid_per_component`；这项任务级授权覆盖训练资料中“直接减面仅作诊断”的旧限制，但不允许修改 `SOURCE_HIGH`、使用通用代理或把不同区域不加区分地整体处理。
   - 复杂连续模型或复杂软表面（例如马鞍主体、布料、皮革、扫描/生成的一体曲面）：若基础体、轮廓块或稀疏 cage 会明显丢失身份，必须从只读高模或已隔离高模区域的新副本执行 `controlled_direct_reduction`，保留原外轮廓、孔洞、边界、主要褶皱和附件关系。若源清单给出 `normalized_work_source.qualified=true`，优先从清单指定的 `SOURCE_HIGH_NORMALIZED_WORK` 新副本减面；否则复制 `SOURCE_HIGH` 或其已证明的复杂区域。只对副本应用减面并完成无破面收尾，绝不能减面、焊接或替换 `SOURCE_HIGH`。
   - 机械、硬表面和明确独立构件：使用 `semantic_reconstruction`，保留决定物体身份的外轮廓、真实组件、开口、负空间、结构台阶和附件位置；宽平面保持稀疏，浅表纹理交给后续烘焙。
   - 同时包含软/复杂区域与结构化或密集重复区域的模型：必须使用 `hybrid_per_component` 并先写清 `region_method_map`。复杂软区域使用受控减面；结构化构件使用语义重建；像木堆、石堆、碎料堆等以整体体块阅读、且单件缝隙不决定主要外轮廓的密集重复区域，使用少量多边形重建整体外轮廓包络，不逐个复制源网格岛。若用户明确要求某个重复区域采用整体包络，该要求直接证明单件缝隙不是交付所需的关键负空间；不得再以“缝隙真实存在”为理由改回逐件语义重建。只有用户未指定方法且高模主轮廓确由单件间隙控制时，才保留相应分隔。
   - 对“布料/皮革覆盖木堆、石堆、碎料堆”等分层混合资产，先把高模的**完整几何连通表面**划入互斥的软表面区与被覆盖聚合区，再分别建形。GLB/FBX 常因法线、UV 或导出切缝产生大量同坐标重复点；当 `duplicate_vertex_ratio > 0.20` 或原始面分量数异常膨胀时，原始 face-component 数量不是语义证据。必须在只读分析数据中按高模对角线 `1e-6` 以内的同坐标点建立 classification-only 邻接，恢复被导出切缝拆开的几何表面后再分类；不得把这个临时焊接写回 `SOURCE_HIGH` 或最终低模。分区原子单位是恢复邻接后的完整几何表面：禁止用 `x/y/z` 范围、AABB 平面或逐面布尔条件截取部分面作为布料，禁止生成缺失原相邻面的三角碎片集合。软表面区域的新副本必须保留选中表面的原始顶点/边/面邻接，然后才允许受控减面；若无法可靠分离，宁可对身份关键表面做保守的整体受控减面，也不得切穿曲面。
     若 classification-only 邻接把几乎全部高模恢复成一个同时包含软表面和被覆盖结构的融合表面，说明导入文件没有可安全复用的语义分界。此时**禁止**再按法线、坐标范围、单面角度或空间裁切强拆布料与木堆，也禁止把一次分区失败写成 Blender 异常后反复修改脚本。直接运行一次已打包的保真回退：
     `blender --background --factory-startup --disable-autoexec --python codex-home/skills/blender-auto-retopo-align/scripts/controlled_reduction_fallback.py -- --input-blend {{WORKING_BLEND}} --output-blend {{OUTPUT_BLEND}} --generation-report {{JOB_DIR}}/generation_report.json --ratio 0.50`。
     它只对新的 `SOURCE_HIGH` 副本整体受控减面，利用导出切缝保护木条、硬边和布料边界，保留融合资产的真实外形，并保持源高模不变。不要传 `--prefer-normalized-work`，因为融合层之间的精确焊接会让减面跨过真实构件边界。该回退是一次建形路线，不是重试、审查或新增门禁；使用后不要再创建或执行 `build_once.py`。
   - 布料/皮革减面不得使用一个固定的极低比例。根据褶皱与边界复杂度分配密度；具有明显深褶、连续下摆和多侧垂落的区域，首版至少保留其原始面的 20%，除非更高比例仍超过整个高模面数。保留边界，禁止 Decimate 后的长刺、锯齿洞和悬空碎片；软表面多边形统一设为 smooth shading，但不得用改变外形的平滑 modifier 掩盖错误拓扑。这是建形参数，不是新增审查或门禁。
   - 聚合包络只能由排除全部软表面后的高模聚合点生成。先求聚合区主轴，再分别从主轴两端的真实暴露点投影出非圆形二维外轮廓；将轮廓简化为每端约 8–24 个按周向排序的多边形点，必要时沿主轴加入 1–3 个中间轮廓环，再用对应边连接。端环必须表达顶层高度变化、两侧收放和堆叠的不规则外形。禁止用 cylinder、cone、sphere、capsule、圆形/椭圆径向环、多个粗圆柱或 AABB/梯形盒代替木堆/石堆；禁止把 `bmesh.ops.create_cone` 或 Blender 圆柱 primitive 用于聚合包络。若无法可靠生成非圆形轮廓挤出体，回退为聚合区高模副本的保守受控减面，绝不能交付通用圆柱或盒代理。被覆盖截面上的包络必须位于布料内侧/遮挡侧，不得遮挡、吞没、穿出或替代布料。两个区域在最终 join 前保持独立且不得跨区焊接；最终低模必须同时包含两区。该约束属于一次建形规则，不新增低模渲染、视觉评分或交付门禁。
   对原木、管束、栏杆、轮辐、支架等区域，先判断它们是“逐件可读结构”还是“整体堆叠包络”。高模的 disconnected mesh island 数量绝不等于语义组件数量，禁止用面数阈值（例如 `faces >= 1000`）直接把网格岛逐个生成成低模组件。逐件可读时，锁定语义主件的数量、中心、两端锚点、主轴/中心线、截面半径和相对层位；整体堆叠时，只从高模外轮廓和必要负空间生成少量包络多边形。树皮片、裂纹、端面碎片、布料褶皱碎片和附着小岛都不是独立主件。不得均匀重排、交换顺序、缩短跨度、放大弯曲或制造高模没有的交叉。这些规则只指导一次生成，不增加第二次测量、低模视觉审查或交付门禁。
   - 本次尝试指令：{{ATTEMPT_GUIDANCE}}
4. 低模必须直接建立在高模本地坐标系：所有构建点使用 `source_high_local`，低模 `matrix_world` 必须等于对应高模的源矩阵。不要归零高模，不要只靠包围盒恢复坐标。
5. 无人值守任务不做左右分开展示；不得给低模保留展示平移。低模使用不透明黄色/橙色材质或对象色，保持可见，不用半透明或 X-ray。
6. 若构建时临时归一化，保存完整 4x4 `work_to_world`，并在保存前按技能的坐标恢复公式回到高模本地坐标。
7. 所有 modifier 应用、曲线转网格和对象 join 完成后，只对新生成低模执行“无破面”收尾：删除零面积/退化面并保证全部顶点坐标为有限数值。不得修改 `SOURCE_HIGH`。开放边、非流形边、游离点边、重复点面和面朝向仅记录为诊断，不得因此拒绝交付。自动拓扑阶段不生成 UV，也不得删除、重展或修改已有 UV；低模原本有 UV 就原样保留，没有 UV 也允许交付，并报告实际 `uv_layers`。最后保存唯一低模候选，不渲染方向图，不执行 FBX 重新导入验证，也不在同一次构建中生成第二版。
   若低模为空、坐标非有限、面数不低于高模或仍含零面积/退化面，明确返回 `RETOPOLOGY_TOPOLOGY_INVALID`。
8. 高模保持不变并可见，把生成阶段场景保存到 `{{OUTPUT_BLEND}}`。仅写出 `build_once.py`、计划或测量图片不算完成；必须实际执行 Blender 构建命令，并在结束前确认 `{{OUTPUT_BLEND}}` 是非空有效 Blend、`{{JOB_DIR}}/generation_report.json` 已存在。
9. 同一次构建结束前写 `{{JOB_DIR}}/generation_report.json`，状态为 `generated_for_user_inspection`。每个 asset 必须包含：
   - `high_object`
   - `low_object`
   - `faces`
   - `triangles`
   - `uv_layers`（必须为大于等于 0 的整数；已有 UV 原样保留）
   - `method_decision`
   - `region_method_map`（`hybrid_per_component` 时必须记录各区域的方法与边界证据）
   - `actual_plugin_use`
   - `coordinate_space: source_high_local`
   - `coordinate_authority: high_object_matrix_world`
   - `presentation_offset_applied: false`
10. 保存后立即停止。不得运行训练技能的 pair audit、topology-flow audit、方向渲染、轮廓评分、ICP 或 FBX 回读；服务器包装器只运行纯坐标恢复、保存后 Blend 指纹检查和 FBX 导出。

不得宣称 accepted、final_pass、validated 或 game_ready。最终状态仍是交给用户检查，但服务器会附加坐标对齐校验。
