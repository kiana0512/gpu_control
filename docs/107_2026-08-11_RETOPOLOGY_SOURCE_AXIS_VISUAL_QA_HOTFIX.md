# Direct V2 源轴向与视觉 QA 热修复（2026-08-11）

## 1. 故障与根因

生产任务 `2b68690b-d616-438f-97e5-503369807c9b` 两次在 99% 失败。拓扑生成、Worker、Codex 认证和
Blender 后处理均已运行，失败点是独立七视图 QA：第一次拒绝方向/前后轮廓，第二次拒绝左右及顶底
轮廓。第二轮候选的几何和 FBX 数据实际为：

- 高模 `100000` 面，候选低模 `172` 面；
- 候选尺寸与高模接近，但带 4 个 N-gon、两个朝内闭合壳体；
- 通用 similarity ICP 选择了约 `0.46°` 旋转；对细长手柄的正交投影，这会产生明显的像素偏移；
- 初始七视图包含 Direct V2 为展示而移开的低模，旧视觉 reviewer 同时接收初始和最终接触图，存在
  把预对齐差异当成最终差异的风险。

## 2. 修复设计

1. 高模仍按面数自动识别并作为唯一坐标标准。
2. Direct V2 低模先使用高模原轴向，严格锁定旋转为 `0°`，只搜索整体等比缩放并重合包围盒中心。
3. 源轴向候选必须通过原有表面距离、中心、尺寸、proper rotation 和 uniform scale 门禁；不通过才
   回退通用 PCA + ICP，不盲目强制方向。
4. 不复制高模对象变换，不使用 XYZ 非等比缩放，不修改原高模或原低模。
5. 仅在 `BAKE_LOW` 交付副本上清除零面积几何、三角化 N-gon、统一闭合壳体朝外法线，再单独生成 UV。
6. 最终仍检查七方向、错误镜像、长刺、可见穿插、折叠、低模面数和 UV，并执行 FBX 全新场景回读。
7. 新增轮廓叠加图：绿色为共同轮廓，蓝色为仅高模，橙色为仅低模。独立 reviewer 只接收最终七视图
   和叠加图；初始展示图继续留档，但明确禁止把预对齐位移作为最终失败。
