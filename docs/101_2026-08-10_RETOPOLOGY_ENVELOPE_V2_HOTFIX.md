# 自动拓扑高低模包围盒恢复 V2 热修复

日期：2026-08-10

## 结论

自动拓扑生成结束后，GPU Control 现在会在不修改低模顶点、边、面和拓扑的前提下，把低模的
世界空间中心、三轴尺寸和高模方向恢复到原始高模坐标，再导出米制 FBX。拓扑过程本身仍由
Direct V2/Codex 完成；坐标恢复只发生在生成结束之后，不会干预或破坏拓扑。

本次仅修改 GPU Control 拥有的交付后处理、Worker 镜像与发布配置，没有修改 Direct V2 技能、
提示词、模型选择、业务工作流、ImageClip 或 ModelViewCreator。

## 故障与修复

问题任务 `b7af5f6b-54ec-43fb-b443-2d57e1af9527` 的第一次重试被旧的尺寸门禁拒绝；随后 V1
安全包围盒实现仍因 Codex 每次生成的低模略有随机差异，在 `21.3855291% > 10%` 时失败。该
10% 上限与“拓扑完成后始终恢复为高模坐标”的业务合同冲突。

V2 删除生成前尺寸偏差百分比上限，改为以下硬安全条件：

- 高模文件、对象和网格必须保持不变。
- 低模只允许修改对象世界变换；低模网格哈希必须保持不变。
- 低模任一尺寸坍缩、比例不是有限正数、恢复后尺寸超过 5% 或中心/线性变换残差超限时拒绝交付。
- 世界空间按三轴分别计算 `high_dimension / low_dimension`，恢复高模中心、尺寸和方向。
- FBX 必须通过 Blender 回读、尺寸/中心回读和米制单位合同回读。

因此，即使生成低模的初始位置或尺寸明显偏离，修复也只调整最终对象变换，不重新拓扑、不拉动
网格顶点，也不会用前端视觉缩放掩盖问题。
