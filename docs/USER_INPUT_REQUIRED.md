# 仍需用户提供的真实材料

以下均是代码无法推断的外部业务/基础设施输入；未要求提供源码设计选择。

1. ComfyUI **Export Workflow (API)** JSON，以及每个业务参数要绑定的 node/input。
2. 每个工作流的 checkpoint、VAE、LoRA、ControlNet 等模型相对路径、字节数和 SHA-256。
3. 自定义节点仓库 URL、完整 commit 和额外 Python/system 依赖。
4. 4090、3090-A、3090-B 的最终局域网 IP/主机名与 SSH 用户。
5. HTTPS 域名、证书方式，或确认仅可信局域网访问。
6. 飞书机器人 Webhook 与签名 Secret（只写服务器 `.env`，不要发进仓库）。
7. 允许的回调域名白名单及各客户的配额/权重。
8. 输入尺寸、像素、文件大小、任务超时、成功/失败数据保留天数。
9. 4090 是否允许自动 OVERFLOW；队列数量、最长等待、GPU 利用率、最低空闲显存和允许时段阈值。
10. 真实 Ubuntu 空机验收窗口、维护窗口与备份目标位置。

提供后应生成或更新：`.env`（不提交）、模型 manifest、custom node lock、工作流版本/兼容性和验收记录。仓库中的示例值均不是生产声明。
