# 管理后台

后台采用 LiClick 视觉语言：紫粉渐变主操作、紧凑图标导航、细描边暗色面板、分段状态胶囊；Secret 只存 `sessionStorage`，关闭会话后失效。

- 总览：优先展示队列、运行/成功/失败、最老等待、可接节点、空闲槽位和预计清空时间。
- 任务中心：支持按业务功能、工作流、公开 API、状态和关键词组合筛选；直接展示提交、开始、
  结束、端到端、真实排队和 GPU wall time。已提交但状态未知的任务不会盲目重提。
  动画序列帧批次在顶层只显示一个父任务，不按帧刷屏；父行展示总进度、成功/总数和节点分布，
  点击“查看”后才分页显示每帧路径、状态、内部 job、节点、尝试次数和错误。完整成功后详情提供
  结果 ZIP 大小、SHA-256 和下载；内部帧 job 不出现在普通最近任务列表。
- 性能分析：只用服务端上报的阶段时间计算中位数、P90、吞吐、阶段基线和字段覆盖；缺失值显示
  “未上报”，不会使用当前时间推断。当前视图基于最近最多 500 条管理任务，不替代长期监控。
- GPU 节点：主界面只显示真实上报过心跳的设备；“暂停接单”“投入调度”“保留 GPU”
  使用中文说明。ComfyUI 可直接打开，维护操作集中在右侧抽屉，支持排空任务、中断、
  释放模型和安全重启。
- 工作流：显示数据库中的真实 API 工作流版本、显存要求、模型要求和启停状态。
- API 客户：默认按来源 IP 自动建档；管理员可修改名称、启停、排队/并发/日配额、
  调度权重、允许 IP 和回调域名。用户软件不需要自己填写 API Key。
- 调度运行说明：先用四步流程解释兼容节点筛选、候选尝试、领取和排队，再展示实时 GPU/CPU
  容量、工作流门禁和风险；4090 高级条件默认折叠，只提交实际改动且只影响后续新任务。
- 日志中心：聚合真实任务和审计记录，可按 ID/IP/操作检索并查看详情；需要完整容器
  日志时跳转 Grafana。
- 系统信息：只读展示真实服务入口、已接入节点和图片 API，不再冒充可编辑系统设置。

管理员拥有全部权限，operator 可运维，viewer 只读。破坏性操作必须填写理由并二次
确认。JWT 到期时前端会自动调用刷新接口并重试原请求；刷新也失效才返回登录页。
页面每 10 秒自动刷新，任务、节点和客户详情可直接点击查看。页面异常先记录浏览器
网络响应的 `X-Request-ID`，再到日志中心或 Loki 检索。
