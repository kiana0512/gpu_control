# 管理后台

后台采用 LiClick 视觉语言：紫粉渐变主操作、紧凑图标导航、细描边暗色面板、分段状态胶囊；Secret 只存 `sessionStorage`，关闭会话后失效。

- 总览：队列、运行/成功/失败、三节点状态和趋势。
- 任务：状态、进度、节点、错误、重试和诊断包。已提交但状态未知的任务不会盲目重提。
- GPU 节点：`Drain` 停止新领取但保留当前任务；`Reserve` 禁止领取；`Release` 将主池恢复 ACTIVE、4090 恢复 OVERFLOW；支持中断、释放模型和安全重启。
- 工作流/API 客户：版本启停、配额、回调白名单和一次性 API Key。
- 调度/告警/日志/审计：修改有边界校验、二次确认和审计记录；日志链接跳转 Grafana。

管理员拥有全部权限，operator 可运维，viewer 只读。破坏性操作必须填写理由并二次确认。页面异常先检查浏览器网络响应的 `X-Request-ID`，再到 Loki 检索。
